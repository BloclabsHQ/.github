# BlocLabs

**Blockchain engineering for companies that ship.**

We build, audit, and scale Web3 infrastructure — smart contracts, wallets, DeFi protocols, and full-stack dApps across EVM chains. Senior engineers from top-tier firms who care about correctness, security, and systems that hold up under real load.

---

## What We Build

- **Smart Contracts** — ERC-20, ERC-721, ERC-1155, governance, vesting, custom protocol logic
- **Wallet Infrastructure** — ERC-4337 account abstraction, non-custodial key management, transaction orchestration
- **DeFi & Tokenization** — AMMs, lending protocols, staking, yield strategies
- **Full-Stack dApps** — From Solidity to React, deployed and monitored
- **Web3 Infrastructure** — Indexers, event systems, multi-chain gateways
